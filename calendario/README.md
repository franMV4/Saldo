# 📅 Calendario fiscal del autónomo 2027 — en tu móvil, con avisos

Gratis. Lo añades una vez a tu Google Calendar, iPhone u Outlook y te avisa **7 días y 1 día antes** de cada plazo: el 303 y el 130 de cada trimestre, el 390, el 347, el 111/115 y la Renta.

**Dirección del calendario (cópiala):**

```
https://raw.githubusercontent.com/franMV4/Saldo/main/calendario/autonomos-2027.ics
```

- **Google Calendar (ordenador):** Otros calendarios → **+** → *Desde URL* → pega la dirección → *Añadir calendario*. Google no copia los avisos de calendarios suscritos: pon tú una notificación por defecto a ese calendario (Configuración → el calendario → *Notificaciones de eventos de todo el día*).
- **iPhone / Mac:** Ajustes → Calendario → Cuentas → Añadir cuenta → Otra → *Añadir calendario suscrito* → pega la dirección.
- **Outlook:** Agregar calendario → *Suscribirse desde la web* → pega la dirección.
- O **[descarga el archivo .ics](https://raw.githubusercontent.com/franMV4/Saldo/main/calendario/autonomos-2027.ics)** y ábrelo (se importa una vez, sin actualizaciones).
